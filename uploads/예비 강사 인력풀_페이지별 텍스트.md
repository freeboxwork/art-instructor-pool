# 예비 강사 인력풀 수요 조사 — 페이지별 텍스트

원본 이미지에서 페이지별 문구를 옮겨 적었습니다.

## 1. 소개

### 배지

예비 강사 인력풀 수요 조사

### 메인 문구

내 지역에  
미술 강의·채용 기회가 생긴다면,  
안내받고 싶으신가요?

### 설명

저희는 미술 전공자와 관련 경력자가  
거주 지역과 경험에 맞는 강의·채용 기회를  
더 쉽게 만날 수 있도록 예비 강사 인력풀  
서비스를 준비하고 있습니다.

### 안내 문구

**현재 적극적으로 구직 중이 아니어도 괜찮아요.**

향후 거주 지역 근처에 조건이 확인된 미술 강의·채용  
기회가 생겼을 때 소식을 받고 싶다면, 활동 가능 지역과  
전공·경력 정보를 간단히 등록해 주세요.

### 제공 내용

| 항목 | 설명 |
|---|---|
| 지역 기반 | 거주 지역 근처 기회 안내 |
| 간편 등록 | 약 1분이면 등록 완료 |
| 선택적 안내 | 원할 때만 안내받을 수 있어요 |

### 하단 안내

- 이번 페이지는 서비스 수요 확인을 위한 사전 등록입니다. 등록만으로 실제 강의나 채용 기회가 보장되는 것은 아닙니다.
- 입력 정보는 서비스 수요 확인과 향후 교육·채용 기회 안내 목적으로만 이용됩니다.

### 버튼

**강사 정보 등록하고 소식 받기**

## 2. 간편 등록

### 제목

간편 프로필 등록

약 1분이면 완료됩니다.

### 입력 항목

| 항목 | 표시 내용 |
|---|---|
| 활동 가능 지역 | 지역을 선택해 주세요 |
| 미술 전공 분야 | 예: 서양화, 시각디자인 |
| 관련 경력 | 경력 없음 / 1년 미만 / 1~3년 / 3년 이상 |
| 아동 수업 가능 여부 | 가능해요 / 어려워요 |
| 이메일 | example@email.com |

### 동의 및 안내

- [ ] 향후 조건에 맞는 교육·채용 기회를 이메일로 안내받는 데 동의합니다.
- 정보 이용 목적과 삭제 요청 방법 보기  >

### 버튼

**프로필 등록 완료하기**

## 3. 완료

### 완료 메시지

등록이 완료되었습니다

참여해 주셔서 감사합니다.

### 안내 문구

서비스 오픈 후 입력하신 지역과 조건에 맞는  
미술 교육·채용 기회가 확인되면  
이메일로 안내해 드리겠습니다.

### 개인정보 관련 안내

정보 삭제를 요청할 수 있습니다.
