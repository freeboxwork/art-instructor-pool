    UTM 링크 만들기

    공유할 채널과 캠페인 이름을 입력하면 분석 가능한 링크를 자동으로 만들어 드립니다.

    LINK SETTINGS

    링크 정보 입력

    채널 빠른 선택

    현재 서비스 소개 페이지로 연결되며 방문자는 A안 또는 B안에 자동 배정됩니다.

    utm_source · 관리자 유입 경로에 표시되는 이름입니다.

    utm_medium · 단체 채팅, 커뮤니티, SNS 등 전달 방식을 적습니다.

    utm_campaign · 링크를 배포하는 모임, 게시글 또는 캠페인을 구분합니다.

    HOW IT WORKS

    UTM 사용 안내

    1. 채널 선택카카오톡, 네이버 카페 등 공유할 곳을 선택합니다.
    2. 모임명 입력예: 미술인모임. 공백은 링크 생성 시 _로 바뀝니다.
    3. 복사 후 공유생성된 링크를 복사해 해당 채널에 그대로 붙여 넣습니다.
    현재 분석 화면 표시 기준

    유입 경로 목록에는 utm_source가 표시됩니다. A/B 버전은 UTM에 넣지 않고 서버에서 공정하게 자동 배정합니다.

    별표(*), 중괄호, 역슬래시는 입력하지 않아도 됩니다. 사용할 수 없는 문자는 링크 생성 시 자동으로 제거됩니다.
